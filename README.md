# 三賽道自學培訓網站 · Practifly AI（v3.0）

> 網址：`https://training.practiflyai.com`（**尚未綁定**；由阿里雲 ESA「函數和 Pages」從本 repo 的 `main` 分支自動部署，待 Scarlett 確認後才綁定網址及對外公布）。最終優化在分支 `v3-final`。
> 舊 repo `InfinityLabHK/practifly-track2-demo` 的 main 仍是已上線的 v2.5；其 `v3-training` 分支是本 repo 的開發紀錄。

## 用途

服務**已報名的參加者及家長**，在家按自己的賽道和年級自學；校內培訓、正式評估及作品提交以章程及大會通知為準。
每條賽道的教學內容、比賽技巧、作品製作方法、小提示及重要事項，分成每個 5–15 分鐘的模組，
次序是「認識 → 例子 → 小練習 → 小提示 → 小測」，完成蓋印。

- 第一頁：機械貓夥伴（顯示牠「現在正在做甚麼」）、一句歡迎、「開始」及「我是老師／校長」入口。
- 四步設定：賽道 → 年級 → 誰在用（孩子自己用／家長陪孩子用／家長自己先看）→ 揀機械貓（3 隻推薦＋看全部 24 款）。
- 首頁「我的培訓」：今天做一件事 → 最近截止 → 這一週 → 我的路線 → 廣場 → 便利貼 → 其他；首次進入有三步新手導覽（可略過，「我的設定」可重看）。
- 機械貓「數字生命」最小版：按裝置本地時間及預寫狀態表（`js/app.js` 的 `lifeAt()`），牠起床、上學、在廣場看書、吃晚飯、做功課、睡覺；週末野餐、踢波、看星星。廣場同學按 seed＋日期各有動作；便利貼只存本機，不生成回覆。不接 AI、不連線；沒有飢餓、生病、懲罰、衰減、打卡獎勵或推送。
- 每條賽道一個「培訓地圖」，模組按章程附錄二的培訓主題排列。
- 「給老師及校長」：校長一頁紙（可列印）、課程對應（只引用章程 12.1、13.1 及附錄一）、模組清單、課堂工具及列印檔。
- 繁（香港、澳門）／简（內地）／EN。

舊連結 `#t1-tc`、`#t2-tc`、`#t3-tc`、`#t1-p5-sc`、`#ws-sc`、`#tpl-sc`、`#preview-lib-sc` 照舊可用，會導到對應新頁或舊列車頁。

## 設定檔 `config.js`

- `dates`：每個日期一個鍵；內容檔用 `{d:鍵}` 引用，改日期只改這裏。
  - `was: '…'`：與章程第 1 版不同，畫面顯示「已延期：原為 …」；`src` 記錄依據。
  - `pending: true`：未確認。**一般網址不顯示【待確認】**；網址加 `?review`（審閱模式）才顯示。對外文字寫「詳情由大會另行通知」。
- `links`：三份《學生需知》（站內 PDF 為主，內地可開；`notesOnline: true` 後才另外顯示 claude.ai 網上版）、報名表（只作頁腳小連結）、舊列車頁。
- `contact`：已報名者的唯一入口 `info@infinitylab.hk`（附統一編號 PF-xxxxx，不附密碼）。
- 內容檔內的 `{pend}` 只在審閱模式顯示【待確認】標記。
- 測試用：網址加 `?now=2026-11-17T16:00` 可注入本地時間（測試機械貓的一天）。

## 三語

- 繁體是正本。改內容只改 `js/c-tc.js`，然後執行 `python3 tools/make_sc.py .` 產生簡體。
- 簡體用語（披萨、块、换组、低／中／高年级、“ ” 引號等）沿用 v2.5 已批簡體版；用語表在 `tools/make_sc.py` 的 `TERMS`。
- 簡體版不顯示港幣金額（章程 4.7）；示範題情境內的 `$` 保留並加註「$ = 港元」。
- EN：新模組的英文版即將推出；現時選 EN 會顯示繁體並附說明。舊列車頁已有 EN。

## 紅線

- 不接任何 LLM；不收集或上傳資料；不用帳號。進度只存本機 `localStorage`（try/catch），頁腳有「清除進度」。
- 只用兩條已批賽道二示範題及現有 130 題賽道一模擬題；不自行新增比賽題目、數字、日期、金額、名額、獎項或服務。賽道三不提供任何數字，不生成圖像。
- 提示只問不答。`tools/check.mjs` 檢查每條選擇題提示以問號結尾，或以「回想」開頭（指向前面看過的內容）；摺頁提示（`flip`）及寫字欄範例不在自動檢查範圍，改內容時要人手確認不給答案。示範先自己試才看。
- 對外不寫合作夥伴的個人姓名；平台名稱用「賽道二平台」「賽道三平台（華南師範大學）」。
- 每頁註明「模擬練習，不是正式比賽題目；以章程及大會公布為準」。

## 檢查

```
python3 tools/build_legacy.py <v2.5 的 index.html> .   # 只在要重建舊列車頁時
python3 tools/make_sc.py .
node tools/check.mjs <v2.5 的 index.html>              # 繁簡結構及答案一致、選擇題提示是問句或「回想…」、示範題與已批原文一字不差
```
