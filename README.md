# 三賽道自學培訓網站 · Practifly AI（v3.0，預覽中）

> 網址：`https://training.practiflyai.com`（**尚未綁定**；由阿里雲 ESA「函數和 Pages」從本 repo 的 `main` 分支自動部署，待 Scarlett 確認預覽後才綁定網址及對外公布）。
> 舊 repo `InfinityLabHK/practifly-track2-demo` 的 main 仍是已上線的 v2.5；其 `v3-training` 分支是本 repo 的開發紀錄。

## 用途

服務**已報名的參加者及家長**。校內培訓屬自選；個人報名的同學用這個網站代替校內培訓自學：
每條賽道的教學內容、比賽技巧、作品製作方法、小提示及重要事項，分成每個 5–15 分鐘的模組，
次序是「認識 → 例子 → 小練習 → 小提示 → 小測」，完成蓋印。

- 首頁「我的培訓」：三步設定（賽道、年級、學生／家長），之後只顯示「今天做一件事」及各賽道進度。
- 每條賽道一個「培訓地圖」，模組按章程附錄二的培訓主題排列。
- 「給老師」：原首頁的課堂工具、課程對應及列印檔。
- 繁（香港、澳門）／简（內地）／EN。

## 結構

| 路徑 | 內容 |
|---|---|
| `index.html` | 外殼（很小；首屏只載入這個檔、`config.js`、`css/app.css`、`js/app.js`、一個語言檔及一張小圖） |
| `config.js` | **設定檔：所有日期、連結、聯絡方法都在這裏**（見下） |
| `js/app.js` | 路由、設定、首頁、培訓地圖、模組引擎、朗讀、顯示設定 |
| `js/c-tc.js` | 內容（繁體，**正本**）：介面文字及各模組 |
| `js/c-sc.js` | 內容（簡體）：由 `tools/make_sc.py` 從繁體正本產生，**不要直接改** |
| `css/app.css` | 樣式（含字體三級、高對比、深色、減少動畫） |
| `play/train.html` | 舊列車頁（v2.5 的賽道二個人／小組挑戰、全班熱身、五格模板、賽道一 5 題快測）；由 `tools/build_legacy.py` 產生，按需載入 |
| `img/` | 角色圖（WebP，由 v2.5 內嵌圖片拆出）；`img/cats/` 24 款機械貓同學造型及廣場背景（v2.7 素材） |
| `js/cats.js` | 機械貓造型名稱（繁、簡、英） |
| `media/`、`files/` | 兩條機械貓短片；賽道二列印 PDF |
| `sw.js` | 離線支援：已載入的內容離線重開仍可用 |
| `tools/` | `build_legacy.py`（拆舊單檔）、`make_sc.py`（產生簡體）、`check.mjs`（內容一致性檢查） |

網址用 `#` 分頁：`#tc`（首頁）、`#t3-tc`（賽道三地圖）、`#t3-m2-tc`（模組）、`#teachers-tc`。把 `tc` 換成 `sc` 或 `en` 即切換語言。
舊連結 `#t1-tc`、`#t2-tc`、`#t3-tc`、`#t1-p5-sc`、`#ws-sc`、`#tpl-sc`、`#preview-lib-sc` 照舊可用，會導到對應新頁或舊列車頁。

## 設定檔 `config.js`

- `dates`：每個日期一個鍵；內容檔用 `{d:鍵}` 引用，改日期只改這裏。
  - `was: '…'`：與章程第 1 版不同，畫面顯示「已延期：原為 …」；`src` 記錄依據。
  - `pending: true`：未確認，畫面顯示【待確認】。
- `links`：三份《學生需知》、報名表（只作頁腳小連結）、舊列車頁。
- `contact`：已報名者的唯一入口 `info@infinitylab.hk`（附統一編號 PF-xxxxx，不附密碼）。
- 內容檔內的 `{pend}` 會顯示【待確認】標記。

## 三語

- 繁體是正本。改內容只改 `js/c-tc.js`，然後執行 `python3 tools/make_sc.py .` 產生簡體。
- 簡體用語（披萨、块、换组、低／中／高年级、“ ” 引號等）沿用 v2.5 已批簡體版；用語表在 `tools/make_sc.py` 的 `TERMS`。
- 簡體版不顯示港幣金額（章程 4.7）；示範題情境內的 `$` 保留並加註「$ = 港元」。
- EN：新模組的英文版尚未加入（第三次預覽）；現時選 EN 會顯示繁體並附說明。舊列車頁已有 EN。

## 紅線

- 不接任何 LLM；不收集或上傳資料；不用帳號。進度只存本機 `localStorage`（try/catch），頁腳有「清除進度」。
- 只用兩條已批賽道二示範題及現有 130 題賽道一模擬題；不自行新增比賽題目、數字、日期、金額、名額、獎項或服務。賽道三不提供任何數字，不生成圖像。
- 提示只問不答（`tools/check.mjs` 會檢查每條提示是否問句）；示範先自己試才看。
- 對外不寫合作夥伴的個人姓名；平台名稱用「賽道二平台」「賽道三平台（華南師範大學）」。
- 每頁註明「模擬練習，不是正式比賽題目；以章程及大會公布為準」。

## 檢查

```
python3 tools/build_legacy.py <v2.5 的 index.html> .   # 只在要重建舊列車頁時
python3 tools/make_sc.py .
node tools/check.mjs <v2.5 的 index.html>              # 繁簡結構及答案一致、提示是問句、示範題與已批原文一字不差
```
